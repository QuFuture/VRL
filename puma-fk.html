PUMA 560 Forward Kinematics

The PUMA 560 is a six-joint articulated arm. The first three joints (waist, shoulder, elbow) place the wrist, and the last three (a spherical wrist) orient the tool. Set the six joint angles and read the tool pose from T₀⁶.

Theory

Each link transform uses the standard DH convention:

Aᵢ = Rot(z,θᵢ)·Trans(z,dᵢ)·Trans(x,aᵢ)·Rot(x,αᵢ)

The tool pose is the product of all six:

T₀⁶ = A₁A₂A₃A₄A₅A₆ = ⎡ R p ⎤ ⎣ 0 1 ⎦

Roll–pitch–yaw angles come from R using the Z-Y-X convention:

yaw = atan2(r₂₁, r₁₁) pitch = atan2(−r₃₁, √(r₃₂² + r₃₃²)) roll = atan2(r₃₂, r₃₃)

Procedure

  1. Press Zero. The upper arm points along x₀ and the forearm points up. Note the tool position.
  2. Press Ready. The whole arm points straight up. Explain the change in z using a₂ and d₄.
  3. Change only θ₁. Confirm that z and the horizontal distance from the base axis stay fixed.
  4. Change θ₄, θ₅ or θ₆ alone. The wrist centre (frame 4 origin) stays put and only the orientation and the d₆ offset move.
  5. Set θ₅ to 0 and change θ₄ and θ₆ in opposite directions. The tool pose does not change. This is the wrist singularity.
  6. Compute T₀³ by hand for one pose and compare with the T₀³ tab.

How the 3D view is drawn

  • The arm is drawn from the computed frames themselves. Each link is a d-segment along zᵢ₋₁ followed by an a-segment along xᵢ.
  • Joint housings sit on each zᵢ₋₁ axis, so you can see which axis each joint turns about.
  • The 15 cm sideways jog between shoulder and forearm is the d₃ shoulder offset.
  • If a DH value were wrong, the drawn arm would be wrong in exactly the same way.
Dimensions follow the published PUMA 560 kinematic model. Joint limits are those of the real arm.
