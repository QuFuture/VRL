Differential Motion and Statics

The same Jacobian answers two questions. For small joint motions δq, the tool moves by δX ≈ J δq. And to push on the world with a force F, the joints must supply torques τ = Jᵀ F. This experiment uses a three-link planar arm, so the tool has a position (x, y) and an orientation φ.

Differential motion: δX = J δq. This is exact only in the limit, so the difference from the true motion grows with |δq|².

Statics by virtual work

With no losses, the work done by the joints equals the work done at the tool for any small motion:

τᵀ δq = Fᵀ δX = Fᵀ J δq for every δq ⇒ τ = Jᵀ F

At a singularity J loses rank, so some forces need zero joint torque. A fully stretched arm can resist a pull along its length with no motor effort, because the structure carries it.

Procedure

  1. Set δθ₁ = 1°. Compare predicted and actual δX, then repeat with 10° and note how the difference grows.
  2. Press Hold a 2 kg load. Record τ and explain why τ₁ is largest.
  3. Change θ₁ with the load held. Find the pose that needs the smallest τ₁.
  4. Press Push on a wall and compare the torques with the load case.
  5. Press Stretched arm and apply a force along the arm. Explain why τ is almost zero.
  6. Turn on the ellipses and explain why the force ellipse is long where the velocity ellipse is short.
Gravity on the links is ignored here so that only the tool force acts. Experiment 7 adds link masses and gravity.
