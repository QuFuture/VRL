RRP Manipulator Inverse Kinematics

An RRP spatial manipulator has a waist joint, a shoulder joint and a telescoping prismatic boom, like the Stanford arm without its wrist. Give it a target point in space and the simulator solves for θ₁, θ₂ and d₃. There are two solutions for almost every point, and you can switch between them.

Forward kinematics

From the DH table, the tool point is

x = d₃ cos θ₁ sin θ₂ y = d₃ sin θ₁ sin θ₂ z = d₁ − d₃ cos θ₂

θ₂ = 90° holds the boom horizontal. θ₂ = 180° points it straight up.

Inverse kinematics

Let r = √(x² + y²) and h = z − d₁. Then

d₃ = √(r² + h²) Solution A: θ₁ = atan2(y, x) θ₂ = atan2(r, −h) Solution B: θ₁ = atan2(y, x) + 180° θ₂ = −atan2(r, −h)

The point is reachable only if d₃ lies within the boom's stroke. When r = 0 the target is on the z₀ axis, θ₁ can take any value, and the arm is singular.

Procedure

  1. Press Front. Record both solutions and confirm the FK error is zero for each.
  2. Move the target along x only. Note which joint variables change and why.
  3. Press On the z₀ axis. Change θ₁ by hand on paper and explain why the tool does not move.
  4. Press Out of reach. Find the boundary using the two reach spheres.
  5. Pick a target, solve it by hand with the formulas, and compare with the table.
  6. Explain why the d₃ value is the same for solutions A and B.
The boom stroke (250–900 mm) and base height are typical teaching values and can be changed in the ROBOT object in the source.
